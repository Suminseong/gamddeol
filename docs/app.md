# 감떨 앱 (프런트엔드 전면 재개편)

IA(`gamddeol_information_architecture_v0.1.json`)의 MVP 화면을 실제로 연결한 브라우저 앱이다. 서버·계정·DB는 없다.

## 구조

| 위치 | 역할 |
|---|---|
| `src/domain/` | 탭 메모리 작업 공간 저장소(`store.ts`), 원고 정규화·코드포인트 오프셋·해시(`text.ts`), 충돌 후보(`conflicts.ts`), 검색, 내보내기 계약(`exportFormat.ts`) |
| `src/router/` | `/gamddeol/` 기준 경로 라우터. 주소에는 화면 경로와 허용된 질의(ID·코드포인트 위치·전송 종류)만 남는다 |
| `src/app/` | 앱 쉘(`shell/`), 화면(`pages/`, `work/`), 공용 UI(`ui/`), 빠른 감평(`quick/`, 알파 보존) |
| `src/ai/` | 작품 안 AI 작업(판본 감평·설정 후보 추출). 키·전송 동의를 보내기 직전에 확인 |
| `src/sim/` | 가상 독자 V10 결정적 계산(`experiments/virtual-readers`와 같은 식, 앱이 실험 폴더를 가져오지 않음) |

## 라우팅과 Pages

- 루트는 `/works`로 이동. v1·later 화면과 UUID가 아닌 ID, 다른 작품의 자료 ID는 404/403.
- 빌드가 `dist/404.html`(= `index.html` 사본)을 만든다. Pages는 안쪽 주소 직접 진입·새로고침에 404 상태와 이 파일을 주고, 앱이 주소를 읽어 화면을 그린다. `scripts/verify-dist.mjs`가 두 파일이 같은지 확인한다.

## 비영속·보안 정책 (바꾸지 않음)

- 작품 자료·키·화면 선호는 탭 메모리에만 있다(저장소·쿠키·서버 없음). 새로고침하면 사라지므로 내보내기 JSON을 쓴다.
- 전송 목적지는 OpenAI Responses 엔드포인트 하나(CSP `connect-src`). 검색어·원고는 주소·기록에 남지 않는다.
- AI 결과는 후보다. 작가가 확정·기각해야 설정이 된다. 인용이 판본 본문에 정확히 없으면 후보로 저장하지 않는다.

## 솔직한 한계

서버·인증·영구 저장 없음 / 삭제 요청 처리 대상 없음 / 가격표가 없어 비용·예산 미표시 / 가상 댓글·반응 생성 미연결 / AI 태그 추출 없음 / DOCX 미지원 / 독자 성향 추가·삭제 없음 / 시드는 결과에 영향 없음(PRNG 없음) / 768–1199px은 아이콘 레일 대신 드로어 / v1·later 화면은 숨김(주소로도 404) / 서버 측 키 전달은 조건상 구현하지 않음.
