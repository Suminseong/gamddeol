# 결정 대기 목록

개발 착수 전에 사업 책임자(사용자)의 승인이 필요한 항목이다. **본 제품의 애플리케이션 코드, 프레임워크, DB 스키마는 승인 전에 넣지 않는다.** 예외는 아래 0절의 개인 검증용 알파뿐이다.

- 결정의 원본과 상태는 노션 프로젝트 허브에서 관리한다(GPT 운영): https://app.notion.com/p/41fcd7a62697815dad08c59d402ade61
- 이 파일은 저장소 쪽 사본이다. 결정이 내려지면 결과와 날짜, 근거 링크를 아래 표에 옮겨 적는다.

## 0. 개인 검증용 알파 (승인됨)

- **결정:** 2026-11-22 참깨빙수가 알파 구현과 GitHub Pages 배포를 승인했다.
- **목표:** GitHub Pages의 단일 웹앱에서 OpenAI API 키를 입력하고 원고를 평문으로 넣어 실제 OpenAI 응답 텍스트를 확인한다. 감평 품질은 평가하지 않는다.
- **범위 제외:** 파일 업로드, 서식 에디터, 자동 저장, 계정·DB·별도 서버, 페르소나·위키.
- **전송 제한:** 실키와 원고는 감평 실행 때만 `https://api.openai.com/v1/responses` 한 곳으로 보낸다. 키는 Authorization 헤더, 원고는 요청 본문으로만 보낸다. 다른 서버·프록시·분석 도구·외부 스크립트는 쓰지 않는다. 브라우저 직접 호출이 막히면 우회 서버를 붙이지 않고 원인과 재현 조건을 기록한다.
- **보관 금지:** 키·원고·결과를 브라우저 영구 저장소, URL, 로그, 저장소·Actions·배포 파일, PR, 스크린샷, 테스트에 남기지 않는다. 자동 검증은 가짜 키와 UI 검사 문자열, 네트워크 모의 응답만 쓴다.
- **알파 스택 (알파에만 해당):** Vite + React + TypeScript 정적 앱, Vitest, Playwright, GitHub Actions → GitHub Pages. 본 제품 스택(2절)과 D01–D07은 이 결정과 별개로 계속 대기한다.
- 자세한 내용: [alpha/README.md](alpha/README.md)

기술 검토 의견서 v0.1 8절의 권장안이다. 승인 전까지 채택하지 않는다.

| 구성 | 제안 |
|---|---|
