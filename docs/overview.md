# 기획 요약 (사업계획서 초안 v0.1 기준)

원본은 사업계획서 초안 v0.1(2026-11-22)이며, 노션 프로젝트 허브의 사업계획서 페이지에 있다. 이 문서는 개발에 필요한 부분만 추린 요약이다. 내용이 다르면 원본이 우선한다.

## 목적

소설 작가를 위한 **범용** 창작 관리 플랫폼. 특정 작가·작품 전용이 아니며 장르와 규모에 관계없이 쓸 수 있어야 한다.

## 제품 원칙

- 작가가 창작의 주체이며 모든 설정과 원고의 최종 결정권을 가진다.
- AI는 본문을 대신 쓰거나 이어 쓰지 않는다. 추출, 정리, 비교, 감평, 제안에만 쓴다.
- AI 없이도 기본 자료 관리 기능은 정상 작동해야 한다.
- AI가 만든 정보는 자동으로 확정 설정에 편입하지 않는다.
- 원고를 다시 등록해도 작가가 정리한 설정과 메모를 초기화하지 않는다.

## 핵심 기능 영역

1. **프로젝트·원고 관리:** 작품별 프로젝트, 회차 등록(일괄 포함), 버전 보존, 검색, 내보내기. 초기 형식은 TXT·Markdown·DOCX.
2. **자동 설정집·위키:** 원고에서 인물·지역·조직 등을 추출해 후보로 제안하고, 작가 승인 후 확정.
3. **설정 일관성 검토:** 추출 정보와 확정 설정을 비교해 충돌 후보를 근거 원문과 함께 제시. 오류 확정이 아닌 검토 후보.
4. **복선 관리:** 최초 등장, 관련 인물·사건, 상태(미회수·진행 중·회수 완료·폐기·의도적 미회수).
5. **시간선·연표:** 작품 내 발생 순서와 독자 공개 순서를 따로 관리.
6. **세계관 제작 도구:** 이름 생성, 템플릿, 랜덤표, 지도 등. AI 없이도 동작하는 것이 기본.
7. **가상 연재·독자 반응 시뮬레이터 (핵심 차별화):** 독자 페르소나 집단에 회차를 연재해 감상, 댓글, 잔존율 변화를 보여 주는 오락·실험 기능. 실제 흥행 예측이 아님을 명시한다. 잔존율은 LLM이 아니라 별도 로직으로 계산하고 난수 시드로 재현 가능하게 한다.

## 단계 계획 (초안)

- **사전 기술 검증(PoC):** 파싱·회차 구분, 추출 정확도, 근거 연결 안정성, 충돌 후보 탐지, 페르소나 감평 차별성, 시뮬레이션 기본 동작, 분량 대비 비용.
- **1차 MVP (초안 8개 항목):** 작품 생성·업로드, 회차 관리·검색, 수동 설정집, AI 설정 추출·승인, 간단한 충돌 후보, 기본 페르소나 감평, 가상 연재 기본 기능, 내보내기.
- **2차:** 복선 회수 추적, 상세 연표, 사용자 정의 항목, 관계도, 독자 장기 기억, 가상 댓글창 등.
- **3차:** 지도, 가상 달력, 세계관 템플릿, 생성 도구, 시리즈·공유 세계관, 외부 가져오기, 공동 창작.

기술 검토 의견서는 MVP를 더 좁힐 것을 권한다. [reviews/tech-review-claude-v0.1.md](reviews/tech-review-claude-v0.1.md) 9절 참고.

## 착수 전 결정 사항 (초안 13장)

제품 운영 형태(웹 우선, 데스크톱·오프라인 고려 여부), AI 제공 방식(BYOK 또는 서비스 모델), 분석 데이터 설계, 시뮬레이션 계산 방식, MVP 범위, 서비스 정책(보관·외부 전송·삭제·저작권), 운영 비용. 현재 상태는 [decisions.md](decisions.md)에서 관리한다.
